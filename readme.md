## Sobre o projeto

Desenvolvido em comemoração do dia do estudantes e Agosto de Lilás. O intuito é fazer com que os estutantes deem uma pequena pausa nos estudos, projetos, atividades para lembrar que por trás da tela, de cada código há uma pessoa que precisa de cuidado e descanso ♥. 

### ✨ Etapas

<ol>
<li>Tela de carregamento simulando um terminal;</li>
<li>Mensagens personalizadas com o nome do usuário;</li> 
<li>Check-in do status de energia do usuário;</li> 
<li>Pergunta sobre o que o usuário precisa;</li> 
<li>Resultado personalizado;</li>
<li>Tirando a sorte com um Biscoitinho da Sorte;</li> 
<li>Missão de autocuidado;</li> 
<li>Mensagem de comemoração do Dia do Estudante;</li>
<li>Opção para o usuário reiciniar a experiência.</li>  
</ol>

``` index.html```
